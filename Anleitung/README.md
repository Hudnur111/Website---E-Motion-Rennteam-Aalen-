# Anleitung: CMS starten & bedienen

`CMS-Anleitung.pdf` ist die vollständige, bebilderte Schritt-für-Schritt-Anleitung für
Redakteur:innen ohne Entwicklungsumgebung – wie das eigene CMS (siehe `cms-app`-Branch)
unter Windows und macOS gestartet, eingerichtet und bedient wird.

Der Ordner `bilder/` enthält die Einzelbildschirme aus dem PDF in voller Auflösung.
